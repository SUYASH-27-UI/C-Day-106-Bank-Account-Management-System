# C Day 106 – Bank Account Management System

## Description
A menu-driven Bank Account Management System developed in C. It allows users to create accounts, check balances, deposit money and withdraw money.

## Features
- Create bank accounts
- Display all accounts
- Search by account number
- Deposit money
- Withdraw money
- Prevent withdrawals above the available balance
- Store account records in a text file

## Technologies Used
- C Programming
- Structures
- Arrays
- Functions
- Pointers
- File Handling

## Files
- `bank.c` – Main C program
- `accounts.txt` – Sample account records

## How to Compile and Run

```bash
gcc bank.c -o bank
./bank
```

On Windows:

```bash
gcc bank.c -o bank.exe
bank.exe
```

## Concepts Learned
Structures, arrays, pointers, functions, searching and file handling.
